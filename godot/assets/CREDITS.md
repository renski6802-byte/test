# 자산 출처

이 폴더에 들어오는 모든 자산은 여기에 출처와 이용조건을 적는다.
적히지 않은 자산은 쓰지 않는다.

## tex/ — 재질 지도

전부 우리가 만든 것이다. `tools/bake_textures.gd` 가 굽는다.

```
godot --headless --path godot --script res://tools/bake_textures.gd
```

| 이름 | 쓰이는 곳 |
|---|---|
| `plank` | 선체 · 갑판 · 난간 · 선루 · 돛대 · 활대 · 키 |
| `canvas` | 돛 · 접은 돛뭉치 |
| `stucco` | 마을의 흰 벽(예정) |
| `tile` | 마을의 기와지붕(예정) |
| `sand` `grass` `rock` | 해안 지형(예정) |

각각 `_albedo.png` 와 `_normal.png` 두 장. 요철은 높이밭을 미분해 만들고,
가장자리를 감아 돌려 이어 붙였을 때 자국이 남지 않게 했다.

**왜 받아오지 않고 굽는가.** 애초 계획은 Poly Haven·ambientCG 의 CC0
텍스처를 받는 것이었다. 이 환경의 망 정책이 두 곳을 막는다(CONNECT 403).
열려 있는 곳은 `raw.githubusercontent.com` 과 npm 인데, 거기서 긁어오는
텍스처는 출처와 이용조건이 흐려서 이 파일에 정직하게 적을 수가 없다.

굽는 편이 이 프로젝트에 더 맞기도 하다. 우리 세계는 텍스처를 UV 가 아니라
지리 좌표로 입힌다 — 수백 km 를 가로지르며 같은 장을 되풀이하므로 사진은
타일 자국이 그대로 드러난다. 여러 배율의 잡음을 겹쳐 만드는 편이 원래 이
문제에 맞는 방법이다.

**망 정책이 열리면** Poly Haven(CC0) 쪽이 벽·기와·바위에서는 더 낫다.
그때는 받은 파일을 `tex/ext/` 에 두고 여기에 자산 이름 · 받은 날짜 ·
라이선스를 줄마다 적는다.

사람 모델과 동작(Mixamo, 무료·Adobe 계정 필요)은 이 환경에서 받을 수 없다.
