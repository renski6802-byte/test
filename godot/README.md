# 대항해 프로토타입 — Godot 4.3

M0 검증용. 배 뒤 자유 시점으로 바다를 달리고, 지나간 자리가 해도에 남는다.

## 여는 법

Godot 4.3 으로 이 폴더(`godot/`)를 연다. 첫 실행 때 임포트가 한 번 돌고, 그 다음부터 바로 뜬다.

## 조작

| | |
|---|---|
| `←` `→` 또는 `A` `D` | 조타 |
| `↑` `↓` 또는 `W` `S` | 돛 3단 (정박 / 반 / 전개) |
| 화면 끌기 | 시점 좌우·상하. 해안과 나란히 달릴 때 이걸 써야 육지가 보인다 |
| 휠 | 줌 |
| `C` 또는 가운데 버튼 | 시점 정면으로 |
| 바다 클릭 | 그쪽으로 뱃머리 |
| `Q` | 선원에게 방향 묻기 |
| `M` | 해도 |
| `Space` (누르는 동안) | 측량 — 넓게 밝히는 대신 느려짐 |
| `E` | 입항 |

리스보아를 나와 **사그레스 · 파루 · 카디스**를 찾는다. 카디스에서 마그레브를 아는 항해사를
태우면 탕헤르와 살레를 물어볼 수 있다.

## 짜임새

```
Main.gd          화면 조립과 조작. 위 78% 바다(SubViewport), 아래 22% 띠
  Voyage.gd      항해 규칙. 그리기가 하나도 안 섞여 있다
  Geo.gd         실제 해안선·항구 자료, 경위도 ↔ 미터
  Ocean.gd       바다 두 겹. 셰이더와 같은 파도를 CPU 로도 계산해 배를 띄운다
  CoastMesh.gd   해안선을 바다에서 본 땅으로 세움
  ShipModel.gd   자리를 채워두는 캐러벨
  Fog.gd         아직 안 그린 해도. 해도와 미니맵이 함께 쓴다
  ui/Band.gd     슬롯 넷 — 초상화 · 대사 · 문맥 · 지도
```

### 바다

`shaders/ocean_near.gdshader` 가 거스너 파도 넷을 겹쳐 꼭짓점을 실제로 민다. 그래서 물마루가
뾰족하고 골이 완만한, 진짜 물결의 모양이 나온다. 그 너머는 `ocean_far` 가 판 하나로 덮되
법선만 흔든다.

**셰이더의 파도 숫자와 `Ocean.gd` 의 `WAVES` 는 반드시 같아야 한다.** 배가 파도를 타려면
CPU 가 같은 높이를 알아야 하기 때문이다. 한쪽만 고치면 배가 물에 잠기거나 뜬다.

### 화면 없이 스크린샷 찍기

```
godot --path godot --rendering-driver opengl3 -- --shot out.png --wait 8 --heading 150 --yaw -35
```

`--chart` 를 붙이면 해도를 펼친 채로 찍는다. `--hour` 로 시각을, `--dist` 로 카메라 거리를 준다.
